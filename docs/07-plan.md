### この順序にした理由

**Phase 1〜3 は AWS なしで完走できる。**
AWS アカウントの準備（作成・課金設定・CLI 設定）は日程が読めないので、
それが律速にならないよう、クリティカルパスから外してある。

Phase 4 で認証を差し替えるとき、変わるのは Guard の署名検証ロジックだけ
（設計判断 5.5）。Phase 1〜3 の成果物は捨てずに済む。

**Phase 5 が最大の未知数。** ここだけは手戻りを覚悟しておく。
逆に言えば、Phase 4 まで終わっていれば「Passkey 以外は全部できた」状態で
9/1 を迎えられる。この保険があるので、Phase 5 に挑む判断（D-5 案 a）は
日程リスクを取っていない。

### D-3 の解釈について

「一般的に利用されている部分にとどめる」という回答を、
**data mode（`createBrowserRouter`）を採用する**と解釈した。

- NestJS を別に立てる純粋な SPA なので、framework mode のサーバ側機能を使わない
- framework mode の `ssr: false` は `clientLoader`/`clientAction` を使う必要があり、
  覚えることが増える。data mode なら `loader`/`action` がそのまま動く
- 練習対象（`loader`/`action`/`Form`/`useFetcher`/Nested Routes）は data mode で全部使えるので、**失うものがない**

解釈違いなら差し戻してほしい。

### D-5：前提が誤っていたので再確認 ★

> **訂正**：初版で「Passkey は Cognito の上位ティアが必要で、無料枠では有効化できない。
> 少額だが課金が発生する」と書いたが、**これは誤り**だった。

2026-08-22 に AWS 公式料金ページで確認した結果:

- Passkey に必要な **Essentials ティアにも 10,000 MAU/月の無料枠がある**
- Essentials は**新規ユーザープールの既定ティア**
- 無料枠は 12 ヶ月の AWS 無料利用枠とは別で、**無期限**
- テストユーザー 1〜2 人なら **1〜2 MAU → $0**

**つまり「コストを避けるために Passkey を諦める」理由が存在しない。**
コストを根拠に「設計を読むだけ」を選んだのであれば、判断をやり直す価値がある。

**決定（2026-08-22）：案 a。Phase 5 まで実装し、Passkey を実際に動かす。**

コストが $0 である以上、「読んで理解」で止める理由がない。
Passkey は案件スタックの中で唯一の未経験領域なので、実際に動かす価値が最も高い。

これにより、当初のスタック（React Router / NestJS / Cognito Passkey /
Terraform / GitHub Actions）が**すべて実地の対象**になった。

### D-10：コストアラートは $0.01 で張る（確定）

無料枠に収まる見込みでも、閾値 **$0.01** の AWS Budgets を設定する。
「無料のはずだから監視しない」ではなく「**無料のはずなのに請求が出たら即座に知る**」。

さらに、これを **Terraform の 1 本目**にする（→ [06 の 6.2](./06-infra-ci.md)）。
課金リソースを作らないので失敗しても何も壊れず、
`init` → `plan` → `apply` → `destroy` の一周を安全に練習できる。
Cognito を作る前に安全網が存在する状態になる。

## 7.3 このドキュメントの使い方

案件で問われるのは「作れるか」ではなく「**なぜそう作ったか**」です。
各ドキュメントの「設計判断」の節が、そのまま想定問答になっています。

特に説明できるようにしておくべき 4 つ:

1. **なぜ Redux を使わないのか** → 3.5 の表
2. **なぜ Repository が `ownerId` を必須で受け取るのか** → 2.4（認可漏れを型で防ぐ）
3. **なぜ `Form` と `useFetcher` を使い分けるのか** → 3.2（遷移するか、しないか）
4. **なぜ `lint` と `typecheck` を分けるのか** → 6.3（ESLint は型を見ない）

2 と 3.4 は同じ原則の裏表です ——
**「チェックを書く」のではなく「通れない構造にする」。**
フロントとバックで同じ方針を採っているのは偶然ではありません。
